安装

在下载页取安装包，先核对 SHA256 再安装。 安装包里不含内核：内核由工作台在首次使用时按清单下载并校验，所以安装包只有几 MB。

当前 Windows 包尚未购买代码签名证书，安装时系统会提示「未知发布者」。哈希核对通过就说明文件没被替换。

账号与额度

不登录也能用，此时是免费档：3 个环境、1 个同时运行。 在账号页或工作台里注册登录后，工作台会拉取你的档位、到期时间和设备绑定，写进本机。

  • 额度在本机强制：创建环境前检查上限，超限只给升级入口，不会静默放行。
  • 离线宽限 14 天：登录过的机器断网后仍可启动已有环境，但不能新建超限环境。
  • 退出登录会清掉本机许可，额度回落到免费档；你的环境数据不受影响。

内核管理

打开工作台的「内核管理」页，选一个版本点下载。工作台会下载对应平台的内核包、校验 SHA256、解压， 并记录实际可执行文件的哈希。之后每次启动环境，都会重新核对那个可执行文件。

可以同时保留多个版本，不用的可以删掉腾空间。我们上架新版本后，它会自己出现在这一页，不用重装工作台。 每个环境绑定一个内核版本，不会自动跟着新版本走：换内核等于换了浏览器版本， 网站会看到这台设备升级了，所以由你在环境页里自己决定什么时候换。

失败时你会看到原因码，不会拿到一个假的可用状态：

  • KERNEL_HASH_MISMATCH：下载或磁盘上的文件和清单对不上，拒启。
  • KERNEL_UNTRUSTED_SOURCE：这个环境绑定的内核版本还没下载、已经不在清单里，或文件缺失。
  • KERNEL_CHANNEL_BLOCKED：这个版本还是预览通道，需要你在安全中心明确同意后才用。

创建环境

在首页新建环境，可以空白新建或从已有环境复制。生成画像后锁定种子，重启后画像保持稳定。 每个环境有自己的 user-data 目录，Cookie、缓存、登录态互不串。

新建时可以选内核版本，默认是最新的稳定版。启动时如果这个版本还没下载会直接拒启。同时运行的环境数受档位限制，超出时会提示当前档位的上限。

代理

在「网络」页添加 HTTP / HTTPS / SOCKS5 代理，然后绑定到环境。代理密码存在本机保险箱里， 经过加密，不进配置明文，也不进日志和诊断包。

开启代理时，内核会同时关掉几条能绕过代理的通道：

  • 关闭 QUIC，避免 UDP 直连绕过 HTTP 代理。
  • 关闭 DNS over HTTPS，避免 DNS 走本机直连。
  • WebRTC 默认不使用非代理 UDP，不暴露真实 IP。
  • 优先 IPv4，避免 IPv6 直连绕过只支持 IPv4 的代理。

要确认环境的真实出口，在环境窗口里打开查 IP 的网站。

实验室

先启动环境，再到「实验室」采集。对照组是工作台当前页，内核组通过本机调试端口采集那个真实的内核窗口， 两边并排比 UA、平台、语言、时区、屏幕、Canvas、WebGL、WebRTC。

没有显示器时内核以无头模式运行，界面会标明，采集结果不会冒充成有界面窗口。

换电脑 / 备份

在设置页导出环境包（.enclave.json），里面是环境定义、画像和代理配置； 代理密码需要你设置一个导出口令才会被加密带走，不设口令就不导出密码。 在另一台电脑登录同一账号后导入即可。Cookie 和浏览记录不在导出范围内。

本机 API

给你自己的脚本用的接口：列出环境、启动、停止，拿到调试端口后用 Puppeteer / Playwright 接管窗口。 默认关闭，在工作台「设置 → 本机 API」打开。免费档不含；Solo 是只读；Pro 和 Team 可以启动和停止。

它只监听 127.0.0.1，每个请求都要带设置页里那个令牌。网页调不了它：带 Origin 头的请求一律拒绝。

列出环境

curl -H "Authorization: Bearer <令牌>" http://127.0.0.1:17891/api/v1/environments

启动一个环境（Pro / Team）

curl -X POST -H "Authorization: Bearer <令牌>" http://127.0.0.1:17891/api/v1/environments/<环境id>/start

启动成功会返回这个环境，和列表里的格式一样；用其中的 debugPort 连 http://127.0.0.1:<debugPort> 即可。 失败时返回和工作台里一样的原因码。同时运行数的上限对 API 同样生效。 代理密码在锁着的保险箱里的环境不会出现在列表里，先在工作台解锁。

  • GET /api/v1/environments　GET /api/v1/environments/<id>
  • POST /api/v1/environments/<id>/start　POST /api/v1/environments/<id>/stop

令牌泄露了就在设置页点「重置令牌」，旧的立刻失效。不要把这个端口反代到公网。

安全

  • 启动前校验真正要执行的内核文件的哈希，不符拒启。
  • 调试端口只绑 127.0.0.1，且限制来源，不接受外部连接。
  • 默认开启沙箱。--no-sandbox 必须你自己在安全中心勾选，并记入本机审计日志。
  • 环境之间不共享任何数据目录。
  • 我们不采集你的浏览内容，工作台不上传环境数据。
  • 发现安全问题请在账号页的联系表单里选择「安全披露」提交。
