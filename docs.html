安装

在下载页取安装包，先核对 SHA256 再安装。 安装包里不含内核：内核由工作台在首次使用时按清单下载并校验，所以安装包只有几 MB。

当前 Windows 包尚未购买代码签名证书，安装时系统会提示「未知发布者」。哈希核对通过就说明文件没被替换。

账号与额度

不登录也能用，此时是免费档：3 个环境、1 个同时运行。 在账号页或工作台里注册登录后，工作台会拉取你的档位、到期时间和设备绑定，写进本机。

  • 额度在本机强制：创建环境前检查上限，超限只给升级入口，不会静默放行。
  • 离线宽限 14 天：登录过的机器断网后仍可启动已有环境，但不能新建超限环境。
  • 退出登录会清掉本机许可，额度回落到免费档；你的环境数据不受影响。

内核准入

打开工作台的「内核」页点准入。工作台会下载对应平台的内核包、校验 SHA256、解压， 并记录实际可执行文件的哈希。之后每次启动环境，都会重新核对那个可执行文件。

失败时你会看到原因码，不会拿到一个假的可用状态：

  • KERNEL_HASH_MISMATCH：下载或磁盘上的文件和清单对不上，拒启。
  • KERNEL_UNTRUSTED_SOURCE：清单里没有这个平台的哈希，或文件缺失。
  • KERNEL_CHANNEL_BLOCKED：这个平台的内核还是预览通道，需要你在安全中心明确同意后才用。

创建环境

在首页新建环境，可以空白新建或从已有环境复制。生成画像后锁定种子，重启后画像保持稳定。 每个环境有自己的 user-data 目录，Cookie、缓存、登录态互不串。

启动时如果内核没准入会直接拒启。同时运行的环境数受档位限制，超出时会提示当前档位的上限。

代理

在「网络」页添加 HTTP / HTTPS / SOCKS5 代理，然后绑定到环境。代理密码存在本机保险箱里， 经过加密，不进配置明文，也不进日志和诊断包。

开启代理时，内核会同时关掉几条能绕过代理的通道：

  • 关闭 QUIC，避免 UDP 直连绕过 HTTP 代理。
  • 关闭 DNS over HTTPS，避免 DNS 走本机直连。
  • WebRTC 默认不使用非代理 UDP，不暴露真实 IP。
  • 优先 IPv4，避免 IPv6 直连绕过只支持 IPv4 的代理。
工作台自己探测出口 IP 走的是你的本机网络，不是环境的代理。要看环境真实出口，在环境里打开查 IP 的网站。

实验室

先启动环境，再到「实验室」采集。对照组是工作台当前页，内核组通过本机调试端口采集那个真实的内核窗口， 两边并排比 UA、平台、语言、时区、屏幕、Canvas、WebGL、WebRTC。

没有显示器时内核以无头模式运行，界面会标明，采集结果不会冒充成有界面窗口。

换电脑 / 备份

在设置页导出环境包（.enclave.json），里面是环境定义、画像和代理配置； 代理密码需要你设置一个导出口令才会被加密带走，不设口令就不导出密码。 在另一台电脑登录同一账号后导入即可。Cookie 和浏览记录不在导出范围内。

本机接口

工作台和内核之间通过一个只监听 127.0.0.1 的本机接口通信。它要求令牌， 并且只接受工作台自身的来源，网页无法跨域调用它。令牌存在你的用户目录下，每次安装各不相同。

自动化接口（给脚本用的那套）默认关闭，免费档不能开启。开启后同样只监听本机回环并要求令牌， 不要把它反代到公网。

安全

  • 启动前校验真正要执行的内核文件的哈希，不符拒启。
  • 调试端口只绑 127.0.0.1，且限制来源，不接受外部连接。
  • 默认开启沙箱。--no-sandbox 必须你自己在安全中心勾选，并记入本机审计日志。
  • 环境之间不共享任何数据目录。
  • 我们不采集你的浏览内容，工作台不上传环境数据。
  • 发现安全问题请在账号页的联系表单里选择「安全披露」提交。
